# Design

The human chrome is colorful and clean. Each section has a quiet wash so you can tell Design from Architecture from Issues at a glance — not a circus, not grey Linear.

## Intent

Read first. The project page is a document. Tickets are a tab, not the home.

## Color

Subtle section tints. Rose for Design, steel for Architecture, violet for Mockups, amber for Decisions, teal for Issues, green for Timeline. Washes stay soft so type stays readable.

## Type

Default body is 13 pt. Settings can move to 12, 14, or 16, and pick a real macOS face (System, New York, Rounded, Helvetica Neue, Georgia, Avenir Next, Menlo, SF Mono). The choice applies from the root, app-wide.

## Layout

One document-style scroll per pane. No list nested inside a scroll. Long markdown gets a sticky subsection outline that jumps in the same scroll.

## Project home

Overview stays at the top. Tabs below: Design, Architecture, Mockups, Decisions & questions, Issues, Timeline. Markdown renders as a preview — headings, lists, code, block quotes, links — never raw source as the reading view.

## Monitor

Studio bird’s-eye: open questions and requirements that are not working. Simple and colorful. Not the ticket cockpit.
