# Still Product Specification

## Vision
Still is a listen-first Android focus companion built by Origin Ark Studio. It anchors users to their stated intention during deep work sessions, speaking only when needed with gentle, single-sentence grounding nudges.

## Core Directives
- **Zero 24/7 Mic:** Microphone is only energized when a user taps "Begin Focus Session".
- **Listen-First:** The companion never talks while the user is speaking.
- **8-Minute Minimum Interval Hard Lock:** A minimum 8-minute cooldown between voice nudges is strictly enforced.
- **Voice Presets & In-App Subscriptions:**
  - `Still Calm` (Free)
  - `Forest Whisper`, `Dusk Serenity`, `Zen Harbor` (Unlocked via `still_voices_monthly` / `still_voices_yearly`)
- **Theme & Accent:** Compose Material 3 with Sage `#718B5F` accent.
- **Android Target:** `minSdk 26`, `targetSdk 35`, Java 21, Kotlin 2.0, R8 enabled for release.
